# Shop — บันทึกของที่ซื้อ แล้วหารกันสิ้นเดือน

เว็บแอพ (mobile-first PWA) สำหรับ 2 คนที่ซื้อของร่วมกัน ใครสะดวกจ่ายไปก่อน
สิ้นเดือนกดปุ่มเดียวรู้เลยว่าใครต้องโอนให้ใครเท่าไหร่
สกุลเงินหลักคือเชเขลอิสราเอล (₪) และวันที่ยึดเขตเวลา Asia/Jerusalem

ดูแนวคิดการออกแบบทั้งหมดได้ใน [DESIGN.md](./DESIGN.md)

## ฟีเจอร์

- **เพิ่มรายการเร็ว ๆ** — เลือกร้าน / ใส่ยอด / เลือกคนจ่าย เสร็จใน 10 วินาที
  (ออกแบบมาเพื่อร้านที่ไม่มีบิลโดยเฉพาะ จดหน้าร้านก่อนลืม)
- ร้านตั้งค่าได้ว่า "มีบิล" หรือ "ไม่มีบิล" — ร้านไม่มีบิลจะมีคำเตือนให้จดทันที
- **แนบรูปสลิป/บิล** ได้ทุกรายการ (ย่อรูปอัตโนมัติก่อนอัพโหลด)
- **อ่านยอดจากบิลอัตโนมัติ (OCR)** — แนบรูปบิลแล้วแอพอ่านยอดรวมให้เอง
  รองรับบิลภาษาฮีบรู (หา סה"כ / לתשלום) ประมวลผลในเครื่องทั้งหมด
  ไม่ส่งรูปไปเซิร์ฟเวอร์ภายนอก (tesseract.js self-hosted ใน `public/ocr`)
- **แยกของส่วนตัวไม่หาร** — ระบุได้ว่าในบิลมีของส่วนตัวของใครกี่บาท
  ส่วนนั้นคิดเต็มให้เจ้าของ ที่เหลือค่อยหารครึ่ง
- **แก้ไขรายการย้อนหลัง** ได้ทุกช่อง (ยอด วันที่ ร้าน คนจ่าย โน้ต รูป)
  ตราบใดที่รอบนั้นยังไม่กดเคลียร์
- **รายการที่ยังไม่เคลียร์** พร้อมสรุป real-time ว่าตอนนี้ใครติดใครอยู่เท่าไหร่
- **เคลียร์ยอด** — คำนวณอัตโนมัติ (รวมของส่วนตัวแล้ว) กดยืนยันแล้วล็อกรายการชุดนั้น
  รายการที่จดเพิ่มทีหลังไปเข้ารอบถัดไป + มีประวัติย้อนหลัง
- **Export CSV** — ดาวน์โหลดทุกรายการเปิดใน Excel / Google Sheets ได้
- **ประวัติการแก้ไข/ลบ (audit log)** — ทุกการแก้หรือลบรายการถูกบันทึกว่า
  ใครทำ เมื่อไหร่ เปลี่ยนค่าอะไร (เก่า → ใหม่) แอดมินดูได้ในหน้าตั้งค่า
- **ตั้งค่า** — เปลี่ยนชื่อ 2 คน, แก้ไข/เพิ่มร้าน

## วิธีรัน

```bash
npm install
npm run dev        # เปิด http://localhost:3000
```

ข้อมูลเก็บใน SQLite ที่ `data/shop.db` (สร้างอัตโนมัติครั้งแรก พร้อม seed
คน 2 คนและร้าน 2 ร้าน) — ตั้งชื่อจริงได้ในหน้า "ตั้งค่า"

Deploy ขึ้น server เดียว (เช่น VPS/Railway) แล้วให้ทั้ง 2 คนเปิดจากมือถือ
เพิ่มลงหน้าจอโฮมเป็น PWA ได้เลย
